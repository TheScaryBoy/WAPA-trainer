# WAPA Trainer

A free, installable web app with seven practice modules built around the categories tested at the WAPA (Wizz Air Pilot Academy) pilot-selection stage:

| Module | Category |
|---|---|
| Mental Arithmetic | Mental Arithmetic |
| Acoustic Memory | Acoustic Memory |
| Concentration | Concentration |
| Passcode Patterns | Analytical Thinking |
| Clock Time | Spatial Orientation |
| Spatial Rotation | Spatial Orientation |
| Six Clocks | Visual Perception |

## Using the app

Open the live link in **Safari on iPhone** and use **Share → Add to Home Screen** to install it like a native app. It works fully offline once installed (including mid-flight), since every module is bundled into a single page with no external dependencies.

This app targets **iOS Safari** as its primary platform; it also works in any modern browser, but iPhone/Safari is what it's built and tested for.
